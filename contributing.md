## 🔍 When Something Does Not Work

A short diagnostic order that resolves most problems in under five minutes.

**Step 1 — is the overlay attached at all?**

Press the menu hotkey with the game focused. Nothing happens means the overlay is
not attached: elevation problem, or the loader was started before the game.

**Step 2 — is the module enabled or just present?**

Every module ships disabled. A module that is listed but not toggled on does
nothing, and this accounts for a large share of "broken" reports.

**Step 3 — does it work alone?**

Load the Clean preset, enable exactly one module. If it works alone but not in
combination, the problem is a dependency between modules, not the module.

**Step 4 — is the version consistent?**

A module binary from one build with a config from another produces exactly the
symptom of "menu opens, nothing works". Re-extract and let the updater run.

**Step 5 — check the log**

The loader writes a log next to itself. The last few lines almost always name the
actual failure. Read it before changing settings at random.

**Common causes, ranked**

| **Rank** | **Cause** | **Share of cases** |
| --- | --- | --- |
| 1 | module not enabled | most |
| 2 | not running elevated | many |
| 3 | game launched after loader | some |
| 4 | version mismatch | few |
| 5 | antivirus quarantined a file | few |

**Order of operations**

1. Close the game and its launcher completely.
2. Run the loader as administrator.
3. Open the **Spoofer** tab and press **Spoof**.
4. **Reboot** — volume serial and SMBIOS are read at boot.
5. Create a fresh account and log in.

**What it does not do**

It does not unban the old account. It gives the machine a new identity so a new
account is not linked to the old ban.

**Skipping the reboot is the most common mistake** — people report "the spoofer
did nothing" when they simply never restarted.
